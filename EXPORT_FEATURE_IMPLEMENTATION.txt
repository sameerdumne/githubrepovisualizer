🚀 HOW IT WORKS
================

Step 1: Analyze Repository
   └─ User enters GitHub URL
   └─ RepoViz fetches and analyzes repo
   └─ Shows structure, insights, analysis

Step 2: Click "Export" Tab
   └─ User sees export options
   └─ Chooses preferred format:
      • Full JSON (structure + code)
      • Structure only (lightweight)
      • Contents only (code focused)
      • Markdown report (human readable)

Step 3: Copy or Download
   └─ Click "Copy" → copies to clipboard
   └─ Click "Download" → saves as file

Step 4: Share with AI
   └─ Upload to ChatGPT, Claude, etc.
   └─ Ask: "Analyze this repository and help debug..."
   └─ AI has full context
   └─ Get better, faster help

📊 EXPORT FORMATS
==================

1. FULL JSON EXPORT
   ├─ Contents: Everything (structure + code)
   ├─ Use for: Complete code review
   ├─ File size: Large (but complete)
   └─ Best with: ChatGPT, Claude

2. STRUCTURE ONLY
   ├─ Contents: Folder hierarchy only
   ├─ Use for: Understanding organization
   ├─ File size: Very small
   └─ Best with: Quick analysis

3. CONTENTS ONLY
   ├─ Contents: All code with metadata
   ├─ Use for: Code-focused debugging
   ├─ File size: Medium
   └─ Best with: Code review

4. MARKDOWN REPORT
   ├─ Contents: Human-readable with code blocks
   ├─ Use for: Documentation & team sharing
   ├─ File size: Large but readable
   └─ Best with: Documentation sharing
