🚀 QUICK START
==============

1. Get API Key:
   Visit: https://makersuite.google.com/app/apikey
   
2. Setup Environment:
   cp .env.example .env.local
   # Add your API key to .env.local
   
3. Install & Run:
   npm install
   npm run dev
   
4. Open Browser:
   http://localhost:3000

5. Try It:
   Enter: https://github.com/facebook/react
