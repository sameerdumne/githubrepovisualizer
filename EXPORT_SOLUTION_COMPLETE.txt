 HOW TO USE

Step 1: Analyze a Repository
   URL: https://github.com/facebook/react (any repo)
   Click: "Analyze Repo"
   Wait: 5-10 seconds

Step 2: View Results
   See: Repository structure, analysis, insights
   Click: "📥 Export" tab (NEW!)

Step 3: Choose Export Format
   Option 1: Full JSON (structure + code) - Complete
   Option 2: Structure Only - Lightweight
   Option 3: Contents Only - Code focused
   Option 4: Markdown Report - Human readable

Step 4: Export Data
   Click: "Copy" to copy to clipboard
   OR
   Click: "Download" to save as file

Step 5: Share with AI
   Open: ChatGPT, Claude, Gemini, etc.
   Upload: JSON file
   Ask: "Analyze this repository and help me debug..."
   Result: AI has complete context! 🎉


═══════════════════════════════════════════════════════════════════════════════
 EXPORT OPTIONS EXPLAINED
═══════════════════════════════════════════════════════════════════════════════

1. FULL JSON EXPORT (Recommended for AI)
   ├─ Contains: Everything
   │  ├─ Metadata (repo name, stats, languages)
   │  ├─ Structure (folder hierarchy)
   │  └─ Contents (all code files)
   ├─ File size: Large (5-10 MB for big repos)
   ├─ Best for: Complete code review, debugging
   ├─ Use case: "Analyze this repo for bugs"
   └─ Supported by: ChatGPT, Claude, Gemini, etc.

2. STRUCTURE ONLY (Fast & Lightweight)
   ├─ Contains: Folder hierarchy only
   │  ├─ Metadata (repo name, stats)
   │  └─ Structure (tree visualization)
   ├─ File size: Very small (100 KB)
   ├─ Best for: Understanding project organization
   ├─ Use case: "Help me refactor this structure"
   └─ Fast for: Quick architecture analysis

3. CONTENTS ONLY (Code Focused)
   ├─ Contains: All code files
   │  ├─ Metadata (repo name, stats)
   │  └─ Contents (code with language info)
   ├─ File size: Medium (5-10 MB)
   ├─ Best for: Code review, security analysis
   ├─ Use case: "Review this code for security issues"
   └─ Great for: Focused debugging

4. MARKDOWN REPORT (Human Readable)
   ├─ Contains: Everything formatted nicely
   │  ├─ Metadata and statistics
   │  ├─ Folder tree visualization
   │  └─ All code in markdown blocks
   ├─ File size: Large (6-12 MB)
   ├─ Best for: Documentation, team sharing
   ├─ Use case: "Share with new developer"
   └─ Perfect for: Team onboarding
